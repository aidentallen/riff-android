# Validation

Built on 2026-10-05 with JDK 17, Android SDK 35, Android Gradle Plugin 8.9.2 and
Gradle 8.11.1. APKs use the standard Android debug signing certificate.

- `:app:assembleDebug` — passed; ARM64, ARMv7, x86_64 and universal APKs produced.
- `:app:lintDebug` — passed with no errors. Remaining warnings concern newer
  dependency versions, native Switch styling, English UI strings and backup rules.
- `:app:testDebugUnitTest` — 6 tests passed: LRC parsing and timing (4), dry audio
  preservation and echo/distortion processing (2).
- APK signature verification — passed for the delivered ARM64 and universal APKs.
- Device tests on an Android 9 / API 28 x86_64 emulator:
  - Import, deduplication, playlist operations, favorites and offline lyric cache — passed.
  - Playback, seek and continued playback after leaving the activity — passed.
  - Native yt-dlp execution and FFmpeg trim/export — passed after correcting the
    editor's shared-library search path. The edited MP3 is saved as a separate
    library track.

The Android 15 emulator was unstable under software emulation; the completed
device checks use the lighter Android 9 emulator. No physical phone or Android
Auto device was available. Live YouTube/SoundCloud extraction, online lyrics,
background downloading on a physical device, and device-specific native effects
have not been verified end to end. Those services are implemented, and errors
are shown in the app; use Settings → Download engine to update yt-dlp if needed.

Any preview screenshots show audio generated by the integration tests. The
delivered app starts with an empty library.
